# SKYBOUND — Mini Adventure

ブラウザーで遊べる、横スクロールアクションゲームのMVPです。

## 起動方法

`index.html` をブラウザーで開いてください。ビルドや追加の依存パッケージは不要です。

## 操作方法

- PC: ← / → または A / D で移動、スペース / ↑ / W でジャンプ
- タッチ端末: 画面下のボタンで移動・ジャンプ
- 光るかけらを集め、旗まで進むとクリアです

## ファイル構成

- `index.html`: ゲーム画面の構造
- `style.css`: レイアウトと見た目
- `game.js`: 描画、操作、ゲーム進行
